# Meta Player Studio — landing

Односторінковий лендинг студії, що створює landing pages для малого та середнього бізнесу.

Ідея: **лендинг показує власну анатомію.** Кожен блок підписаний технічною позначкою (`02 · Задача: назвати проблему`), а перемикач «Показати логіку» в шапці підсвічує блоки і пояснює, яку задачу виконує кожен.

## Стек

Чистий HTML + CSS + JS, без збірки і залежностей. Шрифти — Google Fonts (Onest, JetBrains Mono).

## Структура

```
.
├── index.html            # розмітка всіх блоків (00–11)
├── css/
│   └── styles.css        # токени, компоненти, адаптив
├── js/
│   └── main.js           # перемикач логіки, «Анатомія», форма
├── assets/
│   ├── icons/
│   │   └── favicon.svg
│   └── images/
│       └── works/        # скріншоти кейсів
├── .editorconfig
├── .gitignore
└── README.md
```

## Запуск локально

Відкрити `index.html` у браузері, або підняти локальний сервер:

```bash
npx serve .
# або
python3 -m http.server 8000
```

## Блоки сторінки

| #  | Блок              | Задача                                   |
|----|-------------------|------------------------------------------|
| 00 | Шапка             | навігація, перемикач логіки, CTA         |
| 01 | Hero              | пояснити, що це і для кого               |
| 02 | Проблема          | назвати проблему                         |
| 03 | Анатомія          | показати метод, а не обіцянки            |
| 04 | Що ви отримуєте   | зробити послугу конкретною               |
| 05 | Процес            | зняти страх невідомого                   |
| 06 | Роботи            | показати результат візуально             |
| 07 | Для кого          | сегментувати, підсилити довіру           |
| 08 | Формат і вартість | прибрати головне невідоме                |
| 09 | Питання           | закрити заперечення                      |
| 10 | Заявка            | мінімізувати тертя                       |
| 11 | Футер             | контакти, документи                      |

## Що треба заповнити перед запуском

Усі місця під реальні дані позначені квадратними дужками `[...]` — пошук по `[` в `index.html` знайде їх усі.

- [ ] Вартість і термін (блок 08) та термін відповіді у формі (блок 10)
- [ ] Відповіді на питання (блок 09)
- [ ] Кейси (блок 06) — картинки покласти в `assets/images/works/`, замінити `.work__media--placeholder` на `<img>`
- [ ] Контакти, соцмережі, реквізити (футер)
- [ ] Сторінка політики конфіденційності
- [ ] Відправка форми — функція `sendLead()` у `js/main.js` (зараз лише логує дані в консоль)
- [ ] `og:image` для превʼю в соцмережах

## Кастомізація

Кольори і розміри — CSS-змінні на початку `css/styles.css`. Акцент змінюється однією змінною `--accent`.
